# GCB 實作決策紀錄

規格模糊或與實務衝突時的處理決定。實作與審查規則時以此為準。

## 共同原則

- **照 GCB 字面判定合格與否**；技術上等價或更嚴格的設定，在檢測結果與報告備註中說明，不自行放寬判定。
- 照字面修正會降低安全性或可能造成中斷時，**不自動修改**，標示「部分修復」或「需人工處理」，並在備註說明原因。
- GCB 原文的明顯錯誤（RHEL 路徑用在 Ubuntu、指令語法錯誤、PDF 斷行）採正確做法，並在程式註解與規格 notes 說明。

## 個別決定

| SSH 加密演算法限制 vs. 不覆寫全系統加密原則 | RHEL 8：0271、0292；RHEL 9：0263、0284 | 使用 crypto-policies 子原則（例：`DEFAULT:GCB-SSH`，只限定 @SSH），兩條可同時合格 | 2026-10-05 |
| SSH Compression | RHEL 8：0287；RHEL 9：0279 | 照字面只認 `no`、`delayed`；預設值（顯示為 yes）判不合格，**不自動修改**，備註說明 OpenSSH 7.4 起 delayed 等同 yes，由人工判斷 | 2026-10-05 |
| 家目錄 .shosts | RHEL 8：0291；RHEL 9：0283 | C 類：只回報，不移動、不刪除 | 2026-10-05 |
| 家目錄 .rhosts | Ubuntu：0071 | B 類（加 `--include-risky` 才處理）：備份到報告的 backup 目錄後移除，回滾放回原位；已安裝 rsh／rlogin 服務時不處理。.forward（0069）、.netrc（0070）維持 C 類；RHEL 的 .rhosts、.shosts 維持 C 類 | 2026-10-06 |
| SSH 主機私鑰擁有者 | RHEL 9：0259 | 照字面要求 root:ssh_keys；備註說明 root:root 權限更嚴格、不影響連線 | 2026-10-05 |

| 停用 fat 檔案系統模組 | RHEL 9：0294 | UEFI 開機（/boot/efi 為 vfat）或 vfat 使用中時略過，否則會無法開機 | 2026-10-05 |

| 防火牆預設拒絕「外出」 | Ubuntu、RHEL 各防火牆規則 | C 類只檢測；預設拒絕「進入」為 B 類，修復前先放行 sshd 埠、迴路介面與已建立連線 | 2026-10-05 |
| GRUB 開機通行碼 | Ubuntu 0037；RHEL 對應項目 | C 類：工具不處理通行碼 | 2026-10-05 |
| 非獨立分割的掛載選項 | Ubuntu：0012、0013、0015–0017、0019–0021、0023–0025、0027、0028；RHEL：/var/tmp、/home 等同類項目 | GCB 未設「若為獨立分割」前提，依字面判**不合格**、需人工（先完成對應的「設定 … 目錄之檔案系統」）；不再列為不適用。已寫入開機設定、尚未重開機時判合格並註明。RHEL「使用者家目錄」三項原文有「若…掛載在獨立檔案系統」，維持不適用 | 2026-10-06 |
| at.allow 與 cron.allow | Ubuntu：0171、0172 | 依 GCB 兩個檔案都建立並設定（root:root、600），不因未安裝 at 而略過；cron 與 at 都未安裝才不適用 | 2026-10-06 |
| 無線網路介面 | Ubuntu：0111；RHEL 同類項目 | 沒有無線介面判**合格**（已符合停用，與 GCB 修復腳本一致），不列為不適用 | 2026-10-06 |

| 預設 umask | Ubuntu：0192 | 依 GCB 也要求 /etc/bash.bashrc 設定 umask 027（非登入的互動式 shell）；login.defs UMASK 影響 cron、sftp 等服務，GCB 未要求，只提示不修改 | 2026-10-06 |
| pam_faillock 設定方式 | Ubuntu：0178、0179 | 依 GCB 範本：preauth 用 required，並加入 `auth sufficient pam_faillock.so authsucc`（pam-auth-update 的 Additional 區最後，Priority -1，避免略過 pam_cap 等模組）；pam_unix 的 success=2 由 pam-auth-update 依其後的 pam_deny／pam_permit 計算，與範本 success=1 等效 | 2026-10-06 |
| /boot/efi 掛載選項 | Ubuntu：0035、0036；RHEL 同類項目 | GCB 原文限「基於 UEFI 的系統」；BIOS 開機時不檢查 /boot/efi，但在說明中註明，改為 UEFI 開機後需重新檢測 | 2026-10-06 |
